# Support

- For setup or usage questions, consult the root README and the files in `开发文档/` first.
- For reproducible non-security defects, open a GitHub Issue with the environment, steps, expected behavior, and actual behavior.
- For feature ideas, open a GitHub Issue describing the problem and the expected outcome.
- For security concerns, follow [SECURITY.md](SECURITY.md); never post secrets or private data publicly.
