# 餐厅订餐系统：项目说明与文档索引

## 项目定位

本项目是一个面向学习与演示的前后端分离餐厅订餐系统。用户可浏览菜品、下单、使用钱包模拟支付、申请退款和评价；管理员可管理菜品、餐桌、订单、用户、钱包与经营数据。

系统不接入真实支付、短信、邮件、对象存储或生产部署设施。任何生产化改造都应重新评估认证密钥、演示账号、数据库凭据、CORS、上传文件存储与审计策略。

## 运行边界

| 项目 | 当前实现 |
| --- | --- |
| 前端 | Vue 3 + Vite，开发端口 `8080` |
| 后端 | Spring Boot，端口 `8081` |
| 前端代理 | `/api` 转发到 `http://localhost:8081`，并移除 `/api` 前缀 |
| 数据库 | MySQL，数据库名 `rrs`，字符集 `utf8mb4`，排序规则 `utf8mb4_bin` |
| 身份认证 | `Authorization: Bearer <token>` |
| 角色 | `1` 普通用户；`2` 管理员 |
| 支付 | 钱包余额模拟支付，不连接第三方支付渠道 |
