# 餐厅订餐系统 - 接口文档 (API Documentation)

## 1. 文档说明

| 项目 | 内容 |
|------|------|
| 项目名称 | 餐厅订餐系统 |
| 文档版本 | V1.1（2026-07-25，按当前控制器校对） |
| 后端基础URL | `http://localhost:8081` |
| 前端开发代理 | `/api` → `http://localhost:8081`；代理会移除 `/api` 前缀 |
| 数据格式 | JSON |
| 认证方式 | `Authorization: Bearer <token>` |

除登录、注册和文件上传外，所有接口均需要登录。文中“管理员”表示登录用户的 `role = 2`；普通用户为 `role = 1`。后端实际接口不包含 `/api` 前缀。

---

## 2. 通用响应格式

### 2.1 成功响应
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "count": 100
}
```

### 2.2 失败响应
```json
{
  "code": 500,
  "message": "错误信息",
  "data": null
}
```

### 2.3 分页参数

| 参数 | 类型 | 说明 |
|------|------|------|
| current | int | 当前页码（从0开始） |
| size | int | 每页条数 |

`current` 小于 0 时按 0 处理；`size` 小于等于 0 时按 10 处理，最大为 100。

### 2.4 接口路径索引

以下索引由当前控制器路径校对，作为路径与 HTTP 方法的快速核对表；详细请求体见后续模块说明。

| 模块 | 方法与路径 | 权限 |
|------|------------|------|
| 用户 | `POST /user/login`、`POST /user/register` | 公开 |
| 用户 | `GET /user/info`、`PUT /user/updateEntity` | 登录用户 |

| 菜品套餐 | `POST /dishes-package/list` | 登录用户 |
| 菜品套餐 | `POST /dishes-package/saveEntity`、`PUT /dishes-package/updateEntity`、`DELETE /dishes-package/delete/{id}` | 管理员 |
| 购物车 | `POST /shipping-car/saveEntity`、`POST /shipping-car/listUser`、`PUT /shipping-car/updateEntity`、`DELETE /shipping-car/delete/{id}` | 登录用户 |

| 状态码 | 说明 |
|--------|------|
