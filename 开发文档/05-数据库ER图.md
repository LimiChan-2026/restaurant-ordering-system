## 3. 实体关系说明

### 3.1 关系类型汇总

| 实体A | 关系 | 实体B | 说明 |
|-------|------|-------|------|
| user | 1:N | collection | 一个用户可收藏多个菜品 |
| user | 1:N | shipping_car | 一个用户有多个购物车项 |
| user | 1:N | orders | 一个用户可有多个订单 |
| user | 1:N | wallet | 一个用户有一个钱包 |
| user | 1:N | messages | 一个用户可有多条消息 |
| user | 1:N | dishes_evaluations | 一个用户可有多条评价 |
| dishes_type | 1:N | dishes | 一个种类下有多个菜品 |
| dishes | 1:N | dishes_package | 一个菜品有多个套餐 |
| dishes | 1:N | collection | 一个菜品可被多次收藏 |
| dishes | 1:N | dishes_evaluations | 一个菜品可有多条评价 |
| dishes_package | 1:N | shipping_car | 一个套餐可在多个购物车中 |
| dishes_package | 1:N | orders_item | 一个套餐可在多个订单项中 |
| orders | 1:N | orders_item | 一个订单有多个订单项 |
| orders | 1:1 | orders_refund_reply | 一个订单可有一个退款申请 |
| orders | N:1 | dishes_table | 多个订单可关联一个餐桌 |
| wallet | 1:N | wallet_info | 一个钱包有多条明细 |
| dishes_evaluations | 1:N | images | 一条评价可有多张图片 |

## 4. 表结构详细说明

### 4.1 用户表 (user)

```sql
CREATE TABLE `user` (
  `id` int(11) unsigned NOT NULL AUTO_INCREMENT COMMENT '用户编号',
  `account` varchar(50) DEFAULT NULL COMMENT '用户账号',
  `username` varchar(50) DEFAULT NULL COMMENT '用户昵称',
  `password` varchar(100) DEFAULT NULL COMMENT '用户密码',
  `avatar` text COMMENT '用户头像',
  `email` varchar(50) DEFAULT NULL COMMENT '用户邮箱',
  `role` int(11) DEFAULT NULL COMMENT '用户角色',
  `gender` tinyint(1) DEFAULT NULL COMMENT '性别：1-女；2-男',
  `birthday` date DEFAULT NULL COMMENT '生日',
  `phone` varchar(255) DEFAULT NULL COMMENT '手机号',
  `create_time` datetime DEFAULT NULL COMMENT '用户注册时间',
  PRIMARY KEY (`id`) USING BTREE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 ROW_FORMAT=DYNAMIC;
```

**字段说明**：
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | 是 | 主键，自增 |
| account | varchar(50) | 是 | 用户账号，唯一 |
| username | varchar(50) | 是 | 用户昵称 |
| password | varchar(100) | 是 | 密码（BCrypt加密） |
| avatar | text | 否 | 头像URL |
| email | varchar(50) | 否 | 邮箱 |
| role | int | 是 | 角色：1-用户，2-管理员 |
| gender | tinyint | 否 | 性别：1-女，2-男 |
| birthday | date | 否 | 生日 |
| phone | varchar(255) | 否 | 手机号 |
| create_time | datetime | 是 | 注册时间 |

### 4.2 菜品种类表 (dishes_type)

```sql
CREATE TABLE `dishes_type` (
  `id` int(11) NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `icon_url` varchar(255) DEFAULT NULL COMMENT '图标URL路径',
  `name` varchar(30) DEFAULT NULL COMMENT '菜品种类名',
  PRIMARY KEY (`id`)

```

---

### 4.3 菜品信息表 (dishes)

```sql
CREATE TABLE `dishes` (

  `status` tinyint(1) DEFAULT NULL COMMENT '状态：0下架，1上架',

  KEY `idx_type_id` (`type_id`)

```

```sql
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='菜品评论图片信息表';
```

### 4.15 消息通知表 (messages)

```sql
CREATE TABLE `messages` (
  `id` int(11) NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `user_id` int(11) DEFAULT NULL COMMENT '用户ID',
  `content` varchar(255) DEFAULT NULL COMMENT '消息内容',
  `type` tinyint(1) DEFAULT NULL COMMENT '消息类型：1系统通知，2订单通知',
  `read_status` tinyint(1) DEFAULT NULL COMMENT '阅读状态：0未读，1已读',
  `create_time` datetime DEFAULT NULL COMMENT '通知时间',
  PRIMARY KEY (`id`),
  KEY `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='消息通知表';
```
