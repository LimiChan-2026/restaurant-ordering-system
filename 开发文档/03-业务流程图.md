### 2.5 订单状态流转流程

```
                           ┌─────────────┐
                           │   开始       │
                           └──────┬──────┘
                                  │
                                  ▼
                           ┌─────────────┐
                           │  创建订单    │
                           │  (待支付)    │
                           └──────┬──────┘
                                  │
                    ┌─────────────┴─────────────┐
                    │                           │
                    ▼                           ▼
             ┌─────────────┐            ┌─────────────┐
             │   支付成功   │            │   取消订单   │
             │  (已支付)    │            │  (已取消)    │
             └──────┬──────┘            └─────────────┘
                    │
                    ▼
             ┌─────────────┐
             │  商家接单    │
             │  (出餐中)    │
             └──────┬──────┘
                    │
                    ▼
             ┌─────────────┐
             │   出餐完成   │
             │  (已完成)    │
             └──────┬──────┘
                    │
                    ▼
             ┌─────────────┐
             │   用户评价   │
             └─────────────┘
```

**订单状态说明**：

| 状态码 | 状态名 | 说明 | 可执行操作 |
|--------|--------|------|------------|
| 1 | 待支付 | 订单已创建 | 支付、取消 |
| 2 | 已支付 | 支付完成 | 接单、退款 |
| 3 | 出餐中 | 正在准备 | 完成出餐 |
| 4 | 已完成 | 订单完成 | 评价、退款申请 |
| 5 | 已取消 | 订单取消 | - |
