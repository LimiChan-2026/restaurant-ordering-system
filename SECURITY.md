# Security Policy

## Supported versions

Security fixes are considered for the latest version on the default branch.

## Reporting a vulnerability

Do **not** include credentials, real user data, database dumps, or reproduction details in a public issue.

This learning project does not currently publish a dedicated private reporting channel. If GitHub's private vulnerability reporting is available for the repository, use it. Otherwise, contact the repository owner through a private contact method listed on the owner's GitHub profile, without disclosing exploit details publicly.

Include the affected version or commit, impact, minimal reproduction steps, and any suggested mitigation. Maintainers will acknowledge valid reports privately when a secure contact path is available.
